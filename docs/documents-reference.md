# Документы VK

Раздел показывает документы текущего аккаунта через `docs.get(owner_id, count, offset)` и постраничный поиск по сохранённым документам через `docs.search(q, search_own=1, count, offset)`. Транспорт использует существующую версию API 5.82, без повторов, редиректов, журналирования запросов и автоматических изменений аккаунта. Запросы отменяются при новом поиске, а ответы другой сессии не показываются.

В референсе Coffee `api/docs/DocsGet.java` передаёт `owner_id`, `offset` и `count`, затем читает `response.items` и `response.count`; `api/docs/DocsGetById.java` использует идентификатор документа и ключ доступа. Реализация Tea написана заново. Дополнительная схема VK описывает [`docs.get` и `docs.search`](https://github.com/VKCOM/api-schema-typescript/blob/master/src/methods/docs.ts); актуальные права токена и доступность этих методов в версии 5.82 проверкой без настоящего аккаунта не подтверждены.

Документы не скачиваются автоматически. По явному нажатию пользователь подтверждает открытие ссылки во внешнем браузере или приложении. Принимаются только HTTPS-ссылки с обычным портом 443 и доменом `vk.com`, `vk.ru` или `userapi.com` (включая поддомены); открытие ограничено известными форматами документов, изображений и медиа. Неизвестные или исполняемые форматы, включая HTML, SVG, скрипты и установщики, не открываются из этого раздела. Контент не запускается внутри приложения; внешнее приложение отвечает за его обработку.

Проверки с синтетическими ответами не подтверждают права токена, доступность конкретных документов или работу стороннего приложения для открытия.
