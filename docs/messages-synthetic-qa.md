# Изолированная проверка сообщений на Android

Сборка `:app:assembleQa` создаёт пакет `com.vktea.qa` с отдельным хранилищем и launcher `com.vktea.msg.SyntheticChatActivity`. В итоговом манифесте удалено разрешение INTERNET; вход и пользовательские данные не используются. Это тестовая сборка, она не заменяет debug или release.

Пример для выделенного эмулятора (подставьте его serial):

```powershell
./gradlew.bat :app:assembleQa
adb -s emulator-5558 install -r app/build/outputs/apk/qa/app-qa.apk
adb -s emulator-5558 shell am start -n com.vktea.qa/com.vktea.msg.SyntheticChatActivity
adb -s emulator-5558 logcat -s VkteaSyntheticQA:I '*:S'
```

Для выбора документа или изображения скопируйте заранее подготовленные синтетические файлы в Download эмулятора и выберите их через системный picker. На панели «QA событие» вызывает событие сообщения, «QA курсор» имитирует ответ `failed=1` с обновлённым курсором, «QA сбой» имитирует разрыв соединения; после него запланирован повтор. Панель и logcat показывают только названия методов и синтетический курсор. Долгим нажатием на первое сообщение откройте пересылку и выберите тестового получателя. Проверьте выбор и подтверждение вложения, запись после выдачи разрешения микрофона, остановку, прослушивание и отправку; пришедшее голосовое использует локально сгенерированный звук.

Синтетический interceptor отвечает на каждый этап сохранения и отправки; для нескольких отправок выдаются разные идентификаторы, а сообщение в текущем чате появляется в локальной тестовой истории после обновления. Содержимое multipart не отправляется в сеть; ответ сервера и сохранённая история имитируются. Отсутствие INTERNET исключает реальный VK-трафик. Результаты эмулятора не подтверждают права токена, работу API VK или микрофона физического устройства.

Для списка диалогов и общего счётчика откройте второй QA-экран:

```powershell
adb -s emulator-5558 shell am start -n com.vktea.qa/com.vktea.msg.SyntheticDialogsActivity
```

Кнопка «QA новое непрочитанное» передаёт синтетическое событие общему экземпляру LongPoll. После обработки должны измениться текст строки реального `DialogsFragment`, значок непрочитанных и счётчик в панели реального `MainActivity`; повторное нажатие увеличивает оба счётчика. Запросы списка и счётчика подменены локальными ответами, а остальные возможные сетевые вызовы этой activity заблокированы отсутствием INTERNET.

## Проверка 27 октября 2026

На отдельном эмуляторе API 37 установлен пакет `com.vktea.qa`; отсутствие INTERNET проверено по собранному APK. Синтетическое событие добавило сообщение в чат, а два события на экране диалогов обновили превью и оба счётчика до 1 и 2. Проверены изменение курсора, повтор после обрыва и задержка при повторных ответах `failed=1`. Долгое нажатие открыло выбор получателя и вызвало синтетическую отправку. Через системный picker выбраны TXT и PNG, подтверждены и проведены через соответствующие тестовые этапы документа и фотографии. Запись и воспроизведение голосового проверены компонентами Android, включая автоматическую остановку через две минуты, остановку и повторное предпрослушивание после завершения. Вход с микрофона компьютера на эмуляторе был отключён. Проверены также синтетическая отправка записи и текстового сообщения. Критических ошибок в crash buffer эмулятора не обнаружено.

Открытие эмулятора и действия в QA-сборке не проверяют содержимое пользовательского аккаунта или реальную передачу данных в VK. Файлы, курсоры, история и ответы в этом сценарии синтетические.

Итоговые проверки: `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug`, `:app:assembleQa` прошли; 415 unit-тестов без ошибок и пропусков, lint — 0 ошибок и 231 предупреждение. Эмуляторная проверка выполнена с Android API 37; физическое устройство и реальный VK API не проверялись.
