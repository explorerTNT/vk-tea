# VK Tea

[![Android CI](https://github.com/explorerTNT/vk-tea/actions/workflows/android.yml/badge.svg)](https://github.com/explorerTNT/vk-tea/actions/workflows/android.yml)

Чай вместо кофе - современный неофициальный клиент ВКонтакте, вдохновлённый легендарным **VK Coffee**.

Оригинальный VK Coffee (`su.operator555.vkcoffee`) не обновляется с конца 2021 года: он собран под старый SDK и 32-битные нативные библиотеки, поэтому не устанавливается на современные смартфоны. VK Tea - чистая реализация его идей на современном стеке: Java, актуальный target SDK, поддержка 64-битных устройств.

## Кредиты

- **OPERATOR_555** (Reversing Solutions, г. Полтава) - автор оригинального клиента VK Coffee (2015–2021). Все авторские указания оригинального проекта сохраняются и уважаются. VK Tea - некоммерческое продолжение идей, написанное с нуля.
- Сообщество VK Coffee - за любовь, тесты и мотивацию. (Оригинальные темы и сайты проекта к настоящему времени недоступны.)
- VK Tea не аффилирован ни с OPERATOR_555, ни с VK.

## Принципы проекта

1. **Референс, а не копипаст.** Оригинальный APK (`su.operator555.vkcoffee`) декомпилируется только для чтения (jadx/apktool) - как референс того, как устроена логика. В репозиторий идёт исключительно код, написанный с нуля на Java. Точечные заимствования - только когда иначе никак, с явным указанием источника.
2. **UI 1 в 1.** Внешний вид оригинала (layouts, drawables, стили, поведение экранов) переносится максимально точно - это часть идентичности VK Coffee.
3. **Музыка - приоритет №1.** Плеер VK Coffee даже без патчей работал отлично: фоновое воспроизведение, очереди, кеш. Цель - повторить этот уровень своими силами и не сломать его по ходу развития.
4. **Мёртвые роуты - WebView.** Разделы и сущности, чьи API-роуты больше не работают (видео-страницы, истории, статьи), открываются как встроенные страницы `m.vk.com`.
5. **Логика как в оригинале.** Внутреннее поведение (навигация, жесты, фичи) повторяет VK Coffee, реализованное заново.

## Что уже работает

- **Авторизация**: прямой вход логин/пароль (капча, 2FA, trusted_hash - поток как в VK Coffee) + резервный вход по токену + предложение сохранить токен после входа
- **Лента 1:1 с Coffee**: посты (текст с кликабельными ссылками/хештегами, «Показать полностью…»), фото-сетки до 10 фото, полноэкранный фото-вьюер с зумом, репост-блоки, видео через Media3-плеер (с fallback на m.vk.com), вложения: опросы с голосованием, аудио/голосовые, ссылки-сниппеты, статьи, документы, альбомы, стикеры, гео
- **Взаимодействия**: лайк (с анимацией), комментарии (просмотр/отправка/лайки/ответы), репост, меню поста (копировать ссылку, скрыть, удалить, пожаловаться)
- **Лента-инфра**: списки (Новостная/Рекомендации/Друзья/Фото/Видео + пользовательские), stories-карусель, кнопка «N новых записей», офлайн-кеш, пагинация `start_from`, OkHttp connection pooling
- **Сообщения**: список диалогов (чат в ранней альфе - допиливаем)
- **Профиль**: аватар, имя, статус, стена
- **Хост**: боковое меню 1:1 (порядок, иконки, счётчики, хедер с аккаунтом), тулбар с дропдауном и бейджем непрочитанных

## Сборка

Требования: JDK 17–21, Android Studio (Ladybug или новее) либо чистый Gradle.

```bash
./gradlew assembleDebug        # debug APK
./gradlew assembleRelease      # release APK (см. подпись ниже)
```

Debug APK кладётся в `app/build/outputs/apk/debug/`.

## Авторизация

Способы входа:

1. **Прямой вход (основной)** - логин/пароль как в оригинальном VK Coffee. Даёт полноценный токен со всеми правами API (лента, сообщения, аудио). Капча и двухфакторка поддерживаются, `trusted_hash` сохраняется для входа без flood-лимитов
2. **Резервный вход по токену** - вставка живого access token (+ secret для nohttps-токенов). Страховка на случай поломки основного входа

После входа приложение предлагает сохранить токен - им можно будет войти, если другие способы лягут.

Примечание: VK ID (OAuth 2.1 + PKCE) пробовали - VK выдаёт таким токенам доступ только к имени/фото (error 1051 на методы API), поэтому для полноценного клиента он не годится. Код остался в `AuthWebViewActivity` на случай изменений политики VK.

## CI/CD

GitHub Actions (`.github/workflows/android.yml`):

- **push / PR в `main`** - сборка debug APK, артефакт `vk-tea-debug`.
- **тег `v*`** - сборка release APK и публикация в GitHub Releases.

Подпись release-сборки настраивается секретами репозитория:

| Секрет | Что это |
| --- | --- |
| `KEYSTORE_BASE64` | keystore, закодированный в base64 (`base64 -w0 keystore.jks`) |
| `KEYSTORE_PASSWORD` | пароль хранилища ключей |
| `KEY_ALIAS` | алиас ключа |
| `KEY_PASSWORD` | пароль ключа |

Без секретов release собирается с debug-подписью (удобно для тестовых установок, не для распространения).

## Структура

```
app/src/main/java/com/vktea/
  auth/          - экран входа, сессия, trusted_hash
  api/           - VK API клиент (официальный UA, nohttps+sig схема Coffee)
  feed/          - лента, посты, вложения (CardsRenderer), пост-экран, комментарии, фото/видео вьюеры
  msg/           - диалоги и чат
  menu/          - боковое меню
  ui/            - настройки, плейсхолдеры
  util/          - русские даты, разбор VK-разметки ссылок
```
